# EcoTrack — frontend

Cliente web de EcoTrack: React + TypeScript + Vite, Tailwind CSS, React Router,
react-leaflet y Recharts. Gestor de paquetes: **pnpm** (no usar npm).

```bash
pnpm install
pnpm dev        # http://localhost:5173 con recarga en caliente
pnpm build      # build de producción en dist/
pnpm lint       # oxlint
pnpm test       # Vitest
```
